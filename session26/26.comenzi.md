# Comenzi SQL - sintaxa generala (sesiunea 26)

Sintaxa generica a fiecarei comenzi din `26.teorie.sql`, cu nume generice
(`nume_tabela_nou`, `nume_coloana`...) in loc de exemple concrete - ca sa
poti reutiliza tiparul pentru orice tabela.

## Partea 0 - Baza de date (schema)

```sql
DROP DATABASE IF EXISTS nume_baza_de_date;
CREATE DATABASE nume_baza_de_date;
USE nume_baza_de_date;
```

## Partea 1 - CREATE TABLE

```sql
CREATE TABLE nume_tabela_nou (
    id           INT AUTO_INCREMENT PRIMARY KEY,
    nume_coloana TIP_DE_DATA NOT NULL,
    alta_coloana TIP_DE_DATA UNIQUE,
    coloana_opt  TIP_DE_DATA,
    creat_la     DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- vezi structura unei tabele deja create
DESCRIBE nume_tabela_nou;
```

Tipuri de date des folosite: `INT` / `BIGINT`, `DECIMAL(10,2)`, `VARCHAR(N)`,
`TEXT`, `DATE`, `DATETIME`, `BOOLEAN`.

## Partea 2 - INSERT

```sql
-- un singur rand
INSERT INTO nume_tabela (coloana1, coloana2)
VALUES (valoare1, valoare2);

-- mai multe randuri, intr-un singur INSERT
INSERT INTO nume_tabela (coloana1, coloana2) VALUES
    (valoare1a, valoare2a),
    (valoare1b, valoare2b),
    (valoare1c, valoare2c);
```

## Partea 3 - SELECT

```sql
-- toate coloanele
SELECT * FROM nume_tabela;

-- doar coloanele care intereseaza
SELECT coloana1, coloana2 FROM nume_tabela;

-- WHERE cu operatori de comparatie: =  !=  >  <  >=  <=
SELECT * FROM nume_tabela WHERE coloana > valoare;

-- AND (toate conditiile trebuie sa fie adevarate)
SELECT * FROM nume_tabela WHERE conditie1 AND conditie2;

-- OR (cel putin o conditie trebuie sa fie adevarata)
SELECT * FROM nume_tabela WHERE conditie1 OR conditie2;

-- BETWEEN - "intre X si Y", inclusiv
SELECT * FROM nume_tabela WHERE coloana BETWEEN valoare_min AND valoare_max;

-- IN - valoarea e una dintr-o lista
SELECT * FROM nume_tabela WHERE coloana IN (valoare1, valoare2, valoare3);

-- IS NULL / IS NOT NULL
SELECT * FROM nume_tabela WHERE coloana IS NULL;
SELECT * FROM nume_tabela WHERE coloana IS NOT NULL;
```

## Partea 4 - ORDER BY

```sql
-- crescator (implicit)
SELECT * FROM nume_tabela ORDER BY coloana;

-- descrescator
SELECT * FROM nume_tabela ORDER BY coloana DESC;

-- sortare pe mai multe coloane (a doua e "de rezerva")
SELECT * FROM nume_tabela ORDER BY coloana1, coloana2;

-- LIMIT - Top N
SELECT * FROM nume_tabela ORDER BY coloana DESC LIMIT n;
```

## Partea 5 - LIKE

```sql
-- contine "text", oriunde in text
SELECT * FROM nume_tabela WHERE coloana LIKE '%text%';

-- incepe cu "text"
SELECT * FROM nume_tabela WHERE coloana LIKE 'text%';

-- se termina cu "text"
SELECT * FROM nume_tabela WHERE coloana LIKE '%text';

-- `_` = exact un caracter (aici: pe pozitia 2)
SELECT * FROM nume_tabela WHERE coloana LIKE '_a%';

-- NOT LIKE - inversul
SELECT * FROM nume_tabela WHERE coloana NOT LIKE '%text%';
```

## Partea 6 - UPDATE

```sql
-- verifici INTAI cu SELECT ce randuri sunt afectate
SELECT * FROM nume_tabela WHERE conditie;

UPDATE nume_tabela SET coloana = valoare_noua WHERE conditie;

-- verifici ca s-a schimbat
SELECT * FROM nume_tabela WHERE conditie;
```

## Partea 7 - DELETE

```sql
-- verifici INTAI cu SELECT
SELECT * FROM nume_tabela WHERE conditie;

DELETE FROM nume_tabela WHERE conditie;
```

## Partea 8 - FOREIGN KEY (FK)

```sql
CREATE TABLE nume_tabela_parinte (
    id   INT AUTO_INCREMENT PRIMARY KEY,
    nume VARCHAR(100) NOT NULL
);

CREATE TABLE nume_tabela_copil (
    id               INT AUTO_INCREMENT PRIMARY KEY,
    nume_tabela_parinte_id INT NOT NULL,
    alta_coloana     TIP_DE_DATA NOT NULL,
    FOREIGN KEY (nume_tabela_parinte_id) REFERENCES nume_tabela_parinte(id)
);
```

## Partea 9 - JOIN

```sql
-- INNER JOIN: doar randurile unde legatura chiar exista
SELECT a.coloana, b.coloana AS alias
FROM tabela_a a
JOIN tabela_b b ON b.id = a.tabela_b_id;

-- JOIN cu mai multe tabele + WHERE + ORDER BY (vin dupa toate JOIN-urile)
SELECT a.coloana, b.coloana AS alias, c.coloana
FROM tabela_a a
JOIN tabela_b b ON b.id = a.tabela_b_id
JOIN tabela_c c ON c.id = a.tabela_c_id
WHERE conditie
ORDER BY a.coloana;
```

## De retinut - toate comenzile, pe scurt

| Comanda | Scop                                                                                                   |
|---|--------------------------------------------------------------------------------------------------------|
| `CREATE DATABASE` / `USE` | alegi in ce baza de date lucrezi                                                                       |
| `DROP DATABASE IF EXISTS` | stergi complet o baza de date                                                                          |
| `CREATE TABLE` | definesti coloane + tipuri + reguli (`PRIMARY KEY`, `NOT NULL`, `UNIQUE`, `DEFAULT`, `AUTO_INCREMENT`) |
| `DESCRIBE tabela` | vezi structura unei tabele                                                                             |
| `INSERT INTO ... VALUES` | adaugi randuri                                                                                         |
| `SELECT ... FROM ... WHERE` | citesti si filtrezi                                                                                    |
| `AND` / `OR` | combini conditii in `WHERE`                                                                            |
| `BETWEEN` | "intre X si Y", inclusiv                                                                               |
| `IN` | valoarea e una dintr-o lista                                                                           |
| `IS NULL` / `IS NOT NULL` | verifici lipsa unei valori                                                                             |
| `ORDER BY ... ASC/DESC` | sortezi rezultatul                                                                                     |
| `LIMIT` | tai rezultatul la primele N randuri                                                                    |
| `LIKE '%text%'` | cauti dupa tipar (`%` = orice, `_` = un caracter)                                                      |
| `NOT LIKE` | inversul unui tipar `LIKE`                                                                             |
| `UPDATE ... SET ... WHERE` | modifici randuri; FARA `WHERE` = tot tabelul                                                           |
| `DELETE FROM ... WHERE` | stergi randuri; FARA `WHERE` = tot tabelul                                                             |
| `FOREIGN KEY ... REFERENCES` | legi un rand de PK-ul din alta tabela, previi date orfane                                              |
| `JOIN ... ON` | combini randuri din mai multe tabele acolo unde FK = PK                                                |

Regula de aur: inainte de `UPDATE` sau `DELETE`, ruleaza ACELASI `WHERE`
intr-un `SELECT` si verifica randurile afectate.
