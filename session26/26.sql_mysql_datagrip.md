# SQL, MySQL si DataGrip - Introducere

## Ai scris asta de multe ori pana acum, in Python:

```python
useri = [
    {"nume": "Ana", "varsta": 28},
    {"nume": "Horia", "varsta": 30},
]
```

Functioneaza perfect - **cat timp ruleaza scriptul**. In momentul in care
inchizi programul, lista `useri` dispare complet din memorie. Data
viitoare cand rulezi scriptul, pornesti iar de la zero.

Pana acum ai rezolvat asta salvand intr-un fisier (CSV, JSON) - merge,
dar se strica repede cand ai multe date sau cand mai multi oameni scriu
in acelasi fisier in acelasi timp (fisierul se poate corupe).

Azi inveti trei lucruri noi care rezolva exact problema asta. **Nu
inlocuiesc Python** - lucreaza IMPREUNA cu el (o sa vezi cum, in sesiunea
27).

---

## Cele trei piese, pe rand

**SQL** e limba in care ceri date. La fel cum in Python ai scrie
`useri.append(...)`, in SQL scrii:
```sql
INSERT INTO useri (nume, varsta) VALUES ('Ana', 28);
```
Nu e un program pe care il deschizi - e doar un set de reguli de
scriere, pe care il "intelege" orice baza de date.

**MySQL** e locul unde chiar STAU datele, permanent, pe disc - nu in
memoria unui script Python care se inchide. Ruleaza tot timpul in
fundal, ca un mic "depozit" la care te poti conecta oricand, chiar si
de pe alt calculator.

**DataGrip** e aplicatia cu care te uiti in acel depozit si scrii SQL
cu un click, fara sa scrii Python pentru asta. E ca un explorator de
fisiere, dar pentru baze de date.

> Pe scurt: **SQL e limba, MySQL e locul, DataGrip e unealta cu care te
> uiti in acel loc.**

## De ce nu faci asta tot din Python?

Poti - o sa faci, chiar in sesiunea urmatoare. Dar la inceput e mai usor
sa vezi CE se intampla direct, cu un click, intr-un tabel pe ecran, decat
sa depanezi in acelasi timp si Python si SQL. De-aceea invatam intai SQL
"pe cont propriu", in DataGrip - abia dupa aceea il punem in spatele
unui script Python.

## Cum te conectezi (pe scurt)

1. Deschide **DataGrip** -> panoul **Database** (stanga) -> **+** ->
   **Data Source** -> **MySQL**.
2. Host `127.0.0.1`, port `3306`, user `cursant`, parola `parola123`.
3. **Test Connection**, apoi **OK**.
4. Deschide `26.teorie.sql` si ruleaza prima comanda cu **Ctrl+Enter**
   (Cmd+Enter pe Mac) - asa rulezi orice comanda pe care ai cursorul.
